Phase 5 Quantitative Test-Set Benchmarks

Evaluated across independent test ROIs in India containing cloud-obscured Sentinel-2 and clear-sky targets.

Evaluation Protocol

Metrics

  • • PSNR — Peak Signal-to-Noise Ratio (dB, higher is better)
  • • SSIM — Structural Similarity Index (0–1, higher is better)
  • • SAM — Spectral Angle Mapper (degrees, lower is better)
  • • MAE / RMSE — Pixel error magnitude (lower is better)

Datasets

Evaluation is stratified across land-cover types (urban, agricultural, forest) and monsoon cloud conditions (20–70% coverage) to reflect real operational scenarios for Indian subcontinent observations.
